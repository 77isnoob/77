# 外企德科销售指南

## 一、公司背景

**外企德科（FESCO Adecco）** 是北京外企人力资源服务有限公司（FESCO）与全球领先的人力资源解决方案供应商德科集团（Adecco Group）的合资企业。

### 核心业务线

| 业务线 | 说明 | 目标客户 |
|--------|------|----------|
| 灵活用工/劳务派遣 | 提供弹性人力资源配置 | 外企、大型民企 |
| 招聘流程外包（RPO） | 端到端的招聘解决方案 | 快速扩张企业 |
| 薪酬福利外包 | 薪资计算、社保公积金代缴 | 无本地HR团队的企业 |
| 人力资源咨询 | 组织架构、薪酬体系设计 | 转型期企业 |
| 人才派遣 | 中高端人才的派遣服务 | 外企驻华机构 |

## 二、销售核心方法论

### 2.1 客户画像分析

**理想客户特征：**
- 在华外资企业（尤其是新设办事处/分公司）
- 快速扩张的互联网/科技公司
- 需要合规用工的大型企业
- 跨区域经营、需要异地社保缴纳的企业

**关键决策人：**
- HR 总监 / HRBP
- 行政总监
- 财务负责人（涉及成本优化时）
- 总经理/CEO（小企业）

### 2.2 销售流程（7步法）

```
1. 线索获取 → 2. 需求挖掘 → 3. 方案定制 → 4. 商务报价 → 5. 合同谈判 → 6. 签约交付 → 7. 续约扩展
```

**第1步：线索获取**
- 渠道：商会活动、LinkedIn、行业展会、老客户转介绍
- 工具：企查查/天眼查筛选新注册外企
- 关键：关注企业工商变更（新增分支机构 = 用工需求）

**第2步：需求挖掘**
- 不要一上来就介绍产品
- 用开放式问题了解痛点：
  - "目前用工方面最大的挑战是什么？"
  - "招聘一个岗位平均需要多长时间？"
  - "跨区域的社保公积金是怎么管理的？"

**第3步：方案定制**
- 根据需求组合业务线
- 重点突出：**合规性 + 成本节约 + 效率提升**
- 用数据说话：预计节省XX%人力成本，缩短XX天招聘周期

**第4-6步：商务推进**
- 报价要有弹性空间
- 强调德科全球品牌背书
- 用成功案例消除顾虑

**第7步：续约扩展**
- 定期回访，挖掘新需求
- 从单一业务线扩展到多条业务线
- 老客户转介绍是最高效的获客渠道

## 三、竞争分析

### 主要竞品

| 竞品 | 优势 | 弱点 |
|------|------|------|
| 中智（CIIC） | 国企背景、政府资源强 | 服务意识相对弱 |
| 上海外服（FSG） | 上海市场份额大 | 全国覆盖不如FESCO |
| 任仕达（Randstad） | 全球品牌 | 本土化不足 |
| 万宝盛华（Manpower） | 外企认知度高 | 价格偏高 |

### 外企德科的差异化卖点

1. **中外合资双重背书**：FESCO的本土资源 + Adecco的全球体系
2. **合规能力强**：深耕中国40年+，各地政策了如指掌
3. **全国服务网络**：覆盖400+城市
4. **数字化平台**：HR SaaS工具支持

## 四、销售话术要点

### 开场白模板

> "X总您好，我是外企德科的XX。注意到贵公司最近在[城市]新开了办公室，在人力合规和用工方面，不知道目前是怎么安排的？很多跟您类似情况的企业都选择了我们的方案，能帮您在合规的前提下节省30%左右的用工管理成本。"

### 应对常见异议

**"我们已经有HR团队了"**
→ "完全理解，我们的服务不是替代您的团队，而是帮他们从重复性事务中解放出来，聚焦在更有战略价值的工作上。"

**"价格太贵了"**
→ "如果算上隐性成本——比如招聘延误的机会成本、合规风险的罚款成本——整体算下来我们的方案其实更经济。我给您算一笔账……"

**"我再考虑考虑"**
→ "没问题，您主要是在考虑哪方面？是方案匹配度还是预算？我可以针对性地补充一些信息帮您做判断。"
